# Kokoro FP32 — Michael and Heart v1

Prepared offline speech resources: Kokoro FP32 with US Michael and Heart. This repository contains only model preparation tools, checksums, license notices, and model Release assets.

The application source is maintained separately.

The publication workflow reproduces the checksum-pinned upstream pack, verifies all 381 files and the archive checksum, and publishes `kokoro-fp32-michael-heart-v1.tar.gz`. Downloads are public and require no GitHub login.

Model weights retain their upstream license; pronunciation resources and dependencies carry their own licenses. See `Notices/Kokoro`, the bundled notices, and `docs/KOKORO_RELEASE_NOTES.md`.
